## 🚀 Как разместить сайт на Vercel (в 2 шага)

### Шаг 1: Загрузка в GitHub
В папке проекта выполните:
```bash
git init
git add .
git commit -m "Video promo studio website"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
git push -u origin main
```

### Шаг 2: Деплой на Vercel.com
1. Зайдите на [vercel.com](https://vercel.com).
2. Нажмите **"Add New..." ➔ "Project"**.
3. Выберите ваш репозиторий и нажмите **"Deploy"**.
4. Сайт за несколько секунд будет опубликован с бесплатным адресом `https://ваш-проект.vercel.app` и защищенным SSL!
